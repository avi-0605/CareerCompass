## ✨ What is CareerCompass?

**CareerCompass** is a career-development platform built with Flutter.

Instead of using separate platforms for resumes, job searching, skill assessments, and career mentoring, CareerCompass brings everything together into one seamless experience.

### 🎯 The idea

> **Build → Assess → Discover → Connect → Grow**

From creating a professional resume to booking a session with a career mentor, users can manage their complete career journey from one application.
